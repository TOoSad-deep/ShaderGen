# 归档目录约束

> 归档状态：本目录及全部子目录只保存历史材料，不是当前开发上下文。

- 不得从归档中的计划、checkbox、“下一步”、TODO、命令、门禁或决策正文派生任务。
- 不得用归档内容覆盖根目录和模块旁的实时 README、`ARCHITECTURE.md`、`PROGRESS.md`、`FEATURES.md` 或当前 `DECISIONS.md`。
- 只有用户明确要求追溯具体历史行为时，才读取与问题直接相关的精确文件。
- 归档内容允许路径、命令、状态、模型和测试数量过期；普通开发不维护其一致性。
- 除新增归档批次、修复归档索引或用户明确要求外，不修改归档正文。
