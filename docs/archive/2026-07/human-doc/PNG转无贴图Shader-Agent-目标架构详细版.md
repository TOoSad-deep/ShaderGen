## 1. 目标与边界

### 1.1 输入域

- **目标输入**：扁平图标 / Logo / 渐变 + 简单光影的伪 3D 图形（如光泽球、按钮、徽章）；单主体或多主体简单遮挡；纯色或简单背景。
- **非目标**：照片、复杂纹理、复杂光影材质、密集文字。此类输入不前置拒绝，跑完后如实输出低还原度报告（见 7.3）。

### 1.2 输出

- 纯程序化、零贴图的 GLSL：WebGL1 GLSL ES 1.0 子集，可直接粘贴 Shadertoy 运行。
- 交付物：`.glsl` 源码 + 渲染图 + 指标报告。

### 1.3 理想效果（验收标准）

| 维度 | 目标 |
|---|---|
| 像素保真 | benchmark 语料上 MAE ≤ 0.03（对标人工复刻案例 0.031） |
| 结构保真 | SSIM ≥ 0.98；拓扑 / 实例数 / 必要图层 **100% 正确（硬约束，不容忍例外）** |
| 主观质量 | 人工盲评偏好率 ≥ 70%（F09 教训：自动指标通过 ≠ 人眼认可） |
| 效率 | 单图端到端 ≤ 5 分钟；LLM 调用 ≤ 8 次 |
| 可复现 | 同输入同版本 → 逐像素一致（同渲染栈） |

## 2. 总体架构

四层 + 一个闭环。场景图 JSON 是全系统唯一状态载体。

```
┌─────────────────────────────────────────────────────────────┐
│ 感知层   PNG → 场景图 JSON（多假设分支 + 置信度 + 单位归一）      │
├─────────────────────────────────────────────────────────────┤
│ 生成层   场景图 JSON → GLSL（模板拼装为主，LLM 只产 typed patch）│
├─────────────────────────────────────────────────────────────┤
│ 优化层   渲染 ⇄ 度量 ⇄ 特征块调度（内环参数 / 外环结构）          │
├─────────────────────────────────────────────────────────────┤
│ 交付层   格式转换 + 两层一致性验证 + 如实报告                     │
└─────────────────────────────────────────────────────────────┘
```

数据流：

```
PNG ──感知──→ 场景图JSON(top-2假设) ──生成──→ GLSL(参数全uniform) ──渲染──┐
        ↑                                                              │
        └──── Stage 0 分支裁决 → Stage k 特征块循环 → Final 联合抛光 ─────┘
                                  │
                        达标/预算耗尽 → 交付层
```

## 3. 中枢数据结构：场景图 JSON

### 3.1 设计原则（铁律）

1. **单一事实源**：GLSL 由 JSON + 模板生成；优化器只改 JSON 数值，外环只改 JSON 结构；代码里不允许出现无主的魔法数字。
2. **结构与参数分离**：一切可调参数在 GLSL 中走 WebGL1 支持的普通 **uniform**，由 JSON 经严格 typed uniform 映射逐项上传；不使用仅 WebGL2 才支持的 Uniform Buffer Object。只有结构编辑（增删特征、换模型）才触发源码重生成与重编译。程序对象按 `(template_id, structural_hash)` 缓存。
3. **单位归一**：所有长度参数按画布高度归一化存储（分辨率无关）；角度一律以 `(cos θ, sin θ)` 参数化（消灭周期折返与镜像歧义）；JSON schema 强制每个参数声明单位与坐标约定。
4. **多假设**：图元 / 颜色场选型不确定时（ΔBIC < 6）保留 top-2 分支下传，由优化层用收敛残差裁决，感知层不做一次性单选。
5. **置信度可推翻**：每个参数带 `confidence` 与 `tunable` 标记；先验强度只影响优化器的初始化和步长，**永远不进入目标函数**（或退火到 0），闭环永远可以推翻感知层。

### 3.2 Schema 要点

```json
{
  "version": "1.0",
  "canvas": {"w": 505, "h": 527, "bg": [1, 1, 1], "alpha_mode": "opaque|straight"},
  "hypotheses": [{
    "id": "h1",
    "objects": [{
      "id": "ball",
      "z": 0,
      "primitive": {"type": "circle|ellipse|rbox|superellipse",
                    "params": {"center": [0.0, 0.055], "r": 0.823},
                    "confidence": 0.99, "tunable": true},
      "color_field": {"model": "radial_nstop",
                      "interp_space": "srgb|linear|oklab",
                      "params": {"origin": [-0.35, 0.95], "stops": [...], "ramp": [0.36, 1.15]},
                      "confidence": 0.9, "tunable": true},
      "features": [
        {"type": "polar_arc_highlight",
         "params": {"r0": 0.905, "sigma": 0.030, "phi": [1.72, 2.56],
                    "intensity": 1.15, "color": [1, 0.99, 1]},
         "footprint": {"mask": "polar_band:0.85-0.96", "weight": 1.0},
         "confidence": 0.85, "tunable": true},
        {"type": "gaussian_shadow", "params": {...}},
        {"type": "rim_light|edge_line|oriented_streak|...", "params": {...}}
      ],
      "occlusion": {"occluded_by": [], "boundary_segments": []}
    }]
  }],
  "meta": {"length_unit": "normalized_by_height", "angle_unit": "cos_sin",
           "degradation": {"noise": 0.0, "banding": false, "jpeg_block": false}}
}
```

`footprint` 字段是优化层"参数足迹重叠图"的输入（见 6.3）。

## 4. 感知层：PNG → 场景图 JSON

原则：**能用确定性 CV 测出来的，不让 LLM 猜**。LLM 只做低置信复核与语义判断。

### 4.1 输入退化估计（前置）

- 检测平坦区噪声功率谱、8×8 块效应（JPEG 转 PNG）、banding 台阶、有效位深。
- 检出退化时：退化建模为输入属性而非场景内容；优化目标对滤波版计算，最终验收对原图如实报告并标注"含输入退化不可达下界"。

### 4.2 分割

- 纯色背景：背景色距离阈值 + 饱和度阈值双掩码交叉验证（淡色阴影与浅背景混淆的教训）。
- **阴影不进分割掩码**：改为估计背景色场后，在颜色残差上以乘性（变暗）模型直接拟合阴影模板。
- 主体-背景可分辨度量（颜色距离 × 边缘梯度能量）低于阈值 → 直接走低可行性报告（早退的一种合法触发）。
- alpha 通道：作为独立的"透明度场"参与拟合；对比基准写进契约——ref 与 render 合成到同一中性底色后逐通道比，外加 alpha 自身 MAE。
- 复杂背景（GrabCut/SAM）：仅作兜底，需建小型选型验证集后再启用。

### 4.3 轮廓提取与图元拟合

- 轮廓点取 AA 过渡带 **iso=0.5 亚像素等值线**（coverage 上 marching squares），不用二值掩码边界（消除 0.5–1px 非零均值偏差）。
- 拟合：代数法（Kasa/Fitzgibbon）只出初值，**几何距离 LM 终拟合**；多模型竞争（圆/椭圆/圆角矩形/超椭圆）。
- 模型选型：ΔBIC < 6 时保留 top-2 分支下传，不提交单假设；可见弧占比 < 180° 时曲率置信度强制降级。
- 遮挡：区分"固有轮廓"与"遮挡边界"（边界另一侧图元颜色连续性检测）；遮挡边界不喂拟合，写入 `occlusion` 字段；残缺轮廓输出"可见弧占比"折减置信度。

### 4.4 颜色场估计

- 模型集：`constant / linear / radial / conic / elliptical_radial / piecewise`，**插值空间（sRGB / linear / OKLab）作为竞争维度之一**（设计工具的渐变默认 sRGB 插值，空间选错会产生参数消不掉的系统偏差带）。
- 样本：掩码 erosion 剔除 AA 过渡带；Huber 鲁棒损失；高光/阴影离群区先掩除。
- 多 stop 初始化：沿射线 1D 变点检测（PELT）。
- 8-bit 量化：拟合采用量化感知似然（σ = 1/√12 LSB）；所有残差阈值以"量化地板 + 实测抖动能量"为下限。
- top-2 候选进入 Stage 0，由收敛残差做最终裁决（选型正确性的最终判据在优化层，不在感知层）。

### 4.5 特征提取

- **检测器与模板一一对应**：外观基元库中每个模板必须有对应的确定性检测器（极坐标高光弧 = 亮区掩码 → 半径聚类 → 圆拟合 → 极角分箱；边缘线 = 径向剖面分析；定向高光 = 残差亮斑椭圆拟合；阴影 = 高斯椭圆拟合）。
- 亮区 vs 镂空/背景透出三特征判别：与估计背景色一致性、边缘剖面（SDF 台阶 vs 软衰减）、alpha。
- 每个特征声明最小可检测尺度（如高光弧径向跨度 ≥ 4px），低于门槛降置信或不建特征。
- 感知 → 生成之间加 **round-trip 自检**：JSON 生成后立即渲染一次，与感知测量在同一坐标系下逐特征比对（一次渲染的成本，抓住坐标翻转/镜像类 bug）。

### 4.6 置信度标定

- 误差棒合成：分割阈值扰动 → 轮廓扰动 → 重拟合参数散布（bootstrap）+ 拟合内协方差（JᵀJ）。
- **合成真值套件标定**：用自己的模板库 + 渲染器随机采样参数生成带真值图标，注入真实退化（AA、抖动、粘连阴影、量化），跑感知层画 reliability diagram，isotonic/Platt 重标定。这是本架构独有的便宜优势。
- 先验封顶：标定后先验精度不得超过经验误差倒数；外环有权将先验清零。

### 4.7 早退（替代输入路由层）

- 触发时机：top-2 模型都试过之后（初始拟合残差天然高，不能按初始残差早退）。
- 报告必须三分：`input_infeasible`（输入超域）/ `model_class_insufficient`（基元库不够，转扩库流程）/ `fit_degenerate`（拟合退化）。只有第一种直接交付低可行性报告。

## 5. 生成层：场景图 → GLSL

### 5.1 两个库

- **SDF 图元库**：circle / ellipse / roundedBox / superellipse / capsule + 平滑布尔（smin 等）。
- **外观基元库**（v1 清单，全部参数化模板）：
  `radial_gradient_nstop`、`linear_gradient`、`color_plane_affine`（复用仓库已有）、`diffuse_wrap`、`rim_light`、`edge_line`、`polar_arc_highlight`、`oriented_streak`、`gaussian_shadow`。
- 每个模板 = GLSL 代码块 + 参数 schema + 适用条件 + **对应感知检测器** + 基元单测渲染（见 8.2）。
- 库是系统能力上限，可扩展：新模板注册必须过 lint + 参数 schema + 单测渲染后才入库，运行中沉淀的模板形成自增长库。

### 5.2 代码生成

- **模板拼装为主干**（确定性）：场景图 → IR → 按拓扑排序发射 GLSL（背景 → 阴影 → 求交/覆盖 → 底色 → 逐特征 → 边缘 AA → 混合）。
- **LLM 的唯一合法产物是 typed patch 或新模板注册**——对场景图 JSON 的结构操作（加/删/换特征模型），或注册进基元库的新参数化模板。LLM 永远不直接产出进编译器的源码文本。这既保全铁律，又是最强的注入安全缓解。

### 5.3 GLSL 规范（lint，CI 强制）

- 模板**直接以 GLSL ES 1.0 子集书写**（不是"桌面 GL 能跑就行"）：常量循环界、禁 `while/do-while`、无隐式 int→float、禁动态索引、禁递归。
- 继承人工案例的坑：`smoothstep(e0,e1,x)` 必须 e0 < e1；`sqrt` 输入 clamp 非负；除法分母加 epsilon；AA 宽度按分辨率换算；颜色累加后 clamp。
- CI 门禁：每个模板与每次结构编辑产物过 `glslangValidator`（ES profile）+ headless Chrome 冒烟渲染。
- 复用仓库 `src/shaderforge/validation/shader_validator.py`（已实现 smoothstep 倒序检测/修复、禁贴图检查），按上两条扩充。
- precision 头统一注入 `#ifdef GL_FRAGMENT_PRECISION_HIGH` 回退，shader 的精度需求写进交付报告。

## 6. 优化层：双层闭环（核心）

### 6.1 渲染底座

- **复用仓库 `PlaywrightWebGL1Renderer`**（优化栈 = 交付栈，从根上消除跨栈参数漂移）；如需内环提速再上 cheap renderer，但必须过 parity 协议（beauty MAE ≤ 3/255、mask IoU ≥ 0.98）。
- 参数全部走 uniform，内环评估**零重编译**；worker 进程池（每 worker 一个独立 context），线程数与随机种子钉死，同 JSON → 同字节输出。

### 6.2 指标体系

- **仲裁指标（贯穿内环、阶段验收、终验三层）**：MAE/ΔE + 分区域 MAE + 边缘 IoU。SSIM（带稳定常数）作参考。
- **硬约束（ConstraintSet，直接拒绝，不进加权总分）**：拓扑正确、实例数正确、required-layer 存在、protected-region 不回退。（F09 教训：自动 objective 赢了、人工盲评 30%——全局像素指标保护不了结构。）
- **LPIPS 只做报告项与盲评 gate 参考**，不做逐 stage 验收（扁平图形是其分布外，且与优化目标不同族会产生指标打架）。
- 最小改善 ε 锚定指标量化地板，防止在指标第 3-4 位小数上磨光预算。

### 6.3 特征块调度器

```
Stage 0: 几何 + 底色，top-2 假设分支各跑一次（预算内），
         收敛残差裁决分支；退出条件 = 结构化残差（经最小特征核
         平滑后）低于特征提取阈值的一半，而非"收敛停滞"

Stage k 循环:
  residual = ref − render(当前)
  → spec-test gate：残差对每个备选底色模型的差分场做投影，
    "换底色模型"与"加新特征"并列候选，BIC 裁决——
    防止把模型误差当成幻影特征提取
  → 从残差重提取优先级最高的下一特征并重初始化参数
  → 足迹重叠图：按 footprint 重叠关系取连通块（通常 1-3 个
    特征、10-30 维），块内联合优化（CMA-ES / BOBYQA）
  → 双闸门验收（全分辨率）：块掩码内指标改善 AND 掩码外指标
    在容差内不退化；失败回滚
  → 回滚签名"掩码内改善/全局恶化"= 补偿对检测器，命中即合并
    更大联合块重试一次
  → 新特征被接受后，与所有足迹重叠邻居强制做一次联合重拟合
  → 按残差能量重排后续优先级（几何 > 底色 > 覆盖特征为硬约束，
    其余动态）
Final: 足迹图中度最高的 top-k 耦合参数子集做小步长联合抛光
```

- 先验：只进初始化与 CMA-ES σ0；参数逐维白化（px/色值/弧度单位混杂）。
- 特征总数 ≤ 12；残差能量低于阈值不建特征（防拟合噪点）。
- 分辨率爬坡：宽特征（底色/晕/阴影）半分辨率优化；宽度 < 4px 的特征（弧/描边/rim）直接全分辨率；**验收一律全分辨率**。
- 并行：只并行"提议"（多个候选参数/候选特征的渲染评估），**验收串行**（对齐仓库 `current_best` 严格单调语义）。
- 优化器抽象为接口 `optimize(params, objective, mask, budget)`：v1 = CMA-ES（块内疑似单峰时 BOBYQA 更省）；v2 原位替换为可微代理（见 10.2）。

### 6.4 外环：LLM 结构编辑

- 触发：内环连续停滞（区分"提议被拒"=疑似耦合，转联合块；与"块内无改进"=真停滞）。
- 输入：误差热力图 + 分区域报告 + 当前场景图 + 基元库目录。
- 动作空间（typed patch）：`add_feature / remove_feature / swap_model / split_hypothesis`。
- **refit-before-accept**：结构编辑必须完成一次内环重拟合后再做贪心评判（否则现任偏置会系统性拒绝正确换型）；不接受则回滚。
- 每阶段允许极少量"微劣化 move"（basin-hopping 式，劣化 < δ），跳出补偿谷。

### 6.5 预算（写进预算契约，非估计值）

- 2000–4000 次半分辨率等效渲染（全分辨率按 4× 计费）；LLM 调用 3–8 次。
- 墙钟：worker 池 4–8 并发下 2–5 分钟。
- 早停：连续 N 次编辑无改善（含 ε 阈值）交付当前最优并如实报告。

## 7. 交付层

### 7.1 格式转换

- 目标：Shadertoy（`mainImage` 包装）/ 仓库 WebGL1 契约。uniform 参数烘焙为字面量出交付版（内环 uniform 版仅用于优化）。

### 7.2 两层一致性承诺（替代"逐像素一致"的不实承诺）

- **同栈逐像素一致**：交付代码在仓库渲染器重渲染，与优化终态逐字节一致——作为回归断言。
- **跨栈容差一致**：headless Chrome（真实 WebGL 语义，SwiftShader/GPU）渲染交付代码，SSIM ≥ 0.99、max per-pixel Δ < 标定阈值。阈值用基元库标定。

### 7.3 如实报告

- 并列报告 MAE / ΔE / SSIM / LPIPS / 分区域误差 / 硬约束通过情况；失败特征逐个列出；输入退化导致的不可达下界单独标注；可行性三分法结论（超域输入如实告知，不硬交付四不像）。

## 8. 工程保障

### 8.1 沙箱

- 编译 + 渲染全部在一次性 worker 进程内：`setrlimit(RLIMIT_CPU/RLIMIT_AS)`、父进程按超时杀进程组、FBO 尺寸上限。
- 编排进程永不编译非模板来源的 shader；任何非模板源码先过静态门禁（大小上限、循环界常量且 ≤ N、禁 while、嵌套深度上限）。

### 8.2 测试策略

- **黄金图回归**：固定语料端到端跑 seeded 优化器，每 case 设指标上下限；模板库任何变更 → 版本 bump → 全语料重跑，任何 case 退步 > Δ 即失败。
- **基元单测渲染**：每个模板固定参数渲染存参考图 + 指标带，扩库回归即时可见。
- **跨栈一致性套件**：同 JSON 在仓库渲染器 vs headless Chrome 的指标必须落容差带内（常驻守门员）。
- **fuzz**：随机场景图 JSON → 必须过 ES 编译、渲染无 NaN；投毒用例（死循环、编译炸弹）必须限时被拒。
- 环境钉死：Mesa/浏览器版本容器化；SSIM/LPIPS 实现与骨干网版本钉死。

## 10. 演进路线

### 10.1 分期

- **MVP**：见《最小骨架快速版》——单主体伪 3D 端到端跑通，验证链路。
- **v1**：本文档全量（多假设、特征块调度、硬约束验收、置信度标定、ES 门禁、测试体系）。
- **v2**：多图元场景与遮挡拓扑；基元库自增长（运行中沉淀新模板）。

### 10.2 v2 最大杠杆：可微代理内环

本任务的前向模型是逐像素解析函数（smoothstep AA 天然连续可微），"可微渲染器" = 把每个模板用 PyTorch/JAX 再写一遍（可由 schema 双端生成，无同步漂移）。梯度法比 CMA-ES 便宜 1–2 个数量级，且联合抛光对特征交互的消化天然更强。优化器接口（6.3）在 v1 就预留替换点，v2 原位替换。

## 附：关键设计决策摘要

1. 无前置输入路由层，可行性由感知残差早退 + 最终指标后置判断。
2. 场景图 JSON 为唯一状态载体；参数 uniform 化；LLM 只产 typed patch。
3. 模型选型后移至优化层（top-2 假设 + 收敛残差裁决 + spec-test gate）。
4. 优化单元 = 足迹重叠连通块，非单特征。
5. 统一仲裁指标 + 硬约束拒绝；LPIPS 不进晋级判据。
6. 先验只进初始化不进目标函数。
7. 交付一致性分两层（同栈逐像素 / 跨栈容差）。
